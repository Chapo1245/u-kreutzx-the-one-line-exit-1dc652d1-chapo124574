A program that writes the funniest one-line resignation letter it can to `/output/entry.txt` — an entry for make.fun's "The One-Line Exit" bounty. One line, one twist: after three years of being told "we're a family here", the writer has finally been disowned.

## Run it

```sh
python3 main.py
```

Running it writes exactly one line (93 characters) to `/output/entry.txt`, byte-identical on every run. Python 3.13, standard library only, no network, no secrets.

## The entry

> Dear Sir, I resign: after three years of 'we're a family here,' I have finally been disowned.

The joke is the flip: the company spent three years calling itself a family, and the letter ends with the writer being disowned — the corporate "family" line turned back on itself in a single word.
